actually known about it. States, per [STYLE.md](STYLE.md):

- **unverified** — recalled from model memory while drafting; existence, attribution, and

  contents not read.

| `dro2026` | "Robust KV Cache Management for LLM Serving under Output Token Length Uncertainty." Cheng, Do, Nguyen (ASU). arXiv:2607.16892, 2026. | read | Assistant pass against the kept full text (2026-07-31). Fractile claim pinned: Proposition IV.2 (p. 5), r* = L_in + F^-1(rho/(rho+1)), rho = cp/cw preemption-to-waste, F the worst-case CDF in the Wasserstein ball; Remark 3 attributes the ratio to the classical (DR-)newsvendor — cite the coupling to routing/config/shared memory as the paper's contribution, not the fractile. Admission-time-only confirmed ("all made before observing actual output lengths", Sec. III-B p. 3; online phase O(1), Sec. IV-C p. 6); periodic re-optimization at 5-10 min ticks (Sec. V-B p. 7); traces BurstGPT + Azure LLM 2024 + ShareGPT (Sec. V-A p. 6); pool-scope control plane over serving groups, simulation only. Two corrections to how finding 7 frames it: the per-request reservation IS a hard bound the data plane enforces by preemption ("preemption occurs when L_in + xi > r", p. 3) — the control plane prices the enforcement event rather than preventing it; and constraint (6e) bounds expected occupancy via Little's law with a headroom factor, so the differentiator is online second-scale forecasting and decode-progress conditioning, not occupancy modeling per se. Authors name online adaptation as future work (p. 9) |
| `tie2026` | "Scheduling LLM Inference with Uncertainty-Aware Output Length Predictions" (TIE, "Tail Inflated Expectation"). Zheng et al. arXiv:2604.00499v2, preprint 2026. | read | Assistant pass against the kept full text (2026-07-31). Log-t confirmed (Sec. 3.1 p. 3, Table 1: log-t KS pass 93.1% vs lognormal 60.3%; deployed with fixed nu = 3.5; scheduled on the censored min(X, max_tokens) because the uncensored log-t mean is infinite, App. B p. 14). The gap claim pinned, App. E p. 22 (future work, not the Limitations section): "Dynamic Distribution Updates During Decoding. Currently, TIE predicts the output length distribution before decoding begins. An interesting direction is to dynamically update the distribution as tokens are generated..." Precision required when leaning on this: TRAIL/ELIS already re-predict POINT estimates during decode (p. 1-2), so the acknowledged gap is distributional decode-time updating specifically. Mechanism: one prediction per request pre-decode (DeBERTa head, R2 0.82/0.76 for mu/sigma), ordering-only score E + beta*CVaR in a single vLLM instance; no admission, no preemption, no pool scope. Two extra differentiators: training needs ~20 resampled generations per prompt (Sec. 7 p. 9), so it cannot train from production logs; Theorem 3.2 (p. 3) derives power-law tails from a termination-rate model, citable for heavy tails being structural. Cites Mitzenmacher and Shahout 2025 as the gap survey |

| `s3-line` | S3 (arXiv:2306.06000; NeurIPS 2023 per secondary citations only, kept PDF is the v1 preprint), TetriInfer (arXiv:2401.11181), SSJF (Qiu et al., arXiv:2404.08509), learning-to-rank scheduling (Fu et al., arXiv:2408.15792, preprint). | read | All four verified on arXiv and read by assistant pass against kept full texts (2026-07-31). Three qualifications the narrative must carry: Fu et al. is the line's strongest POSITIVE result and inverts a blanket weak-record reading — it abandons the pointwise target for relative rank (bucket classifiers at 85-97% accuracy score Kendall tau 0.17-0.24 and can lose to FCFS, Tables 2-3) and finds decode-time re-scoring worthless for ordering (App. H); each paper's own headline end-to-end numbers are positive; and all four evaluate ordering/placement/batching only — the line is silent on admission, so "wrong frame for admission" is an inference from structure, not their tested claim. Unoccupied-combination check: none of the four is content-blind or age-conditioned (all read the prompt with a trained proxy; TetriInfer's reserve-dynamic decrements a frozen estimate, which is age arithmetic, not conditioning); only TetriInfer is pool-scope (admits everything); only S3 revokes (per-sequence reservation recovery with re-admission, not an admission bound) |
